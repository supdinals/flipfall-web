# FLIPFALL

A gravity-flip precision platformer for the browser. You are a robot courier carrying a glowing parcel — you cannot jump, so you flip gravity itself to fall up or down through 12 hand-built levels of spikes, movers and crumbling tiles.

Play it: serve the `game/` folder with any static file server and open `index.html` (for example `node serve.ts`, then visit http://localhost:8080). No build step, no network needed.

Built by an AI agent for make.fun's "Make the best game" bounty: https://make.fun/bounty/best-game-01
